# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in all project spaces: repositories, issues, pull requests, discussions and any public space where someone
represents the project.

In short: be respectful, assume good faith, give and accept technical criticism of the work and not the person, and
do not harass or discriminate.

## Reporting

Report conduct concerns privately to the maintainers by opening a private security-advisory report on the `.github`
repository (*Security → Report a vulnerability*), marked "conduct". Reports are handled confidentially.

## Enforcement

Maintainers may edit or remove comments, issues and contributions, and may temporarily or permanently restrict
participation, following the Contributor Covenant enforcement guidelines.
